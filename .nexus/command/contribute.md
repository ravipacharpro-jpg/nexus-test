# /contribute

Bundle `.nexus/community/added.json` + the referenced files, push to a
`community/<date>` branch, and open a PR to `ravipacharpro-jpg/nexus-agent`.
Mark contributed entries `status: "contributed"`.

Note: recording was offline (local ledger); this command only runs when the user
is online + authed. Nothing is sent automatically. Public-only, no secrets.
